⚠️ วิธีนี้ต้องใช้ Personal Access Token (PAT) ของ GitHub ตัว token จะถูกเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น (localStorage) — ห้ามเปิดหน้านี้บนเครื่องที่ผู้อื่นใช้งานร่วม เพราะคนที่เปิดหน้านี้จะเห็น token และเข้าถึง GitHub ของคุณได้
